# Real-time Subtitles

Real-time subtitles show live captions of what participants say, at the bottom of the screen.

## Showing subtitles

Any participant can click **Show subtitles** in the control bar. It starts captioning for the room if it is not running yet, and shows the captions to you. Each participant who wants to read them clicks the button for themselves, and **Hide subtitles** hides them again.

The button only appears when your instance administrator has set up subtitles, see [Real-time Subtitles](../self-hosting/configuration/subtitles.md) for the setup and the supported speech-to-text providers.

## Limitations

- Caption accuracy depends on audio quality and the speech-to-text provider
- Speaker identification is limited
- Internet connectivity issues may cause caption delays
